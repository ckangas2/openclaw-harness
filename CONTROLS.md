# Controls

Every control in the engine, the failure it exists for, and when to remove it. A control without an incident should not exist; a control whose expiry condition is met should be switched off, re-run on the eval sets, and deleted if nothing gets worse.

How to check expiry: run the eval set with the control off (config flag or a one-line patch) against the same set with it on. "Expires when" means the off arm shows the failure at most once in 30 cases on the original set and never on the held-out set.
